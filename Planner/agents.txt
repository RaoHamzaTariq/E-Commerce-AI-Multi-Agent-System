## 🛠️ Simplified Agent Flow (For Customers Only)

Your chatbot will internally route user messages to the right agent based on intent — powered by OpenAI Agent routing or manual logic.

### 🧩 Agents You’ll Need (Customer-Focused Only)

| Agent | Description | Real-Time Use |
|-------|-------------|----------------|
| 🛍️ Product Finder | Search products using natural language | “Show me shoes under 2k” |
| 🤖 Support Chat | Help with policies, returns, shipping | “Can I return after 10 days?” |
| 🚚 Order Tracker | Track orders using ID/email | “Where’s my order #1023?” |
| 🧠 Recommendation | Suggest products based on context | “What goes with this jacket?” |
| 📝 Review Analyzer | Summarize what others are saying | “Are these shoes durable?” |

You **don't need** agents like Sales Forecast or Inventory Alerts — those are internal.

## ⚙️ System Architecture (Simplified for Chatbot UX)

```txt
Customer (chat on website)
        ⬇️ WebSocket
     FastAPI Server
        ⬇️ Router (Detect Intent)
    ┌─────────────────────────────┐
    |   Agent Manager (Dispatcher)|
    └─────────────────────────────┘
        ⬇️
   🛍️ 🧠 🚚 🤖 📝 (Agents run in background using OpenAI SDK)
        ⬇️
   Reply returned to client
```
